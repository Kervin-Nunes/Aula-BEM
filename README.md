# Aula BEM — Boas Práticas de CSS 📚

Repositório de estudo focado na aplicação da metodologia **BEM (Block, Element, Modifier)** para organização e nomenclatura de classes CSS. O projeto demonstra a estruturação de um componente de listagem de produtos com variações de estilo, usando boas práticas de escrita e manutenção de CSS.

## 🧠 O que é BEM?

BEM é uma metodologia de nomenclatura de classes CSS que divide os elementos em:

- **Block** — componente independente (ex: `produto`)
- **Element** — parte do bloco (ex: `produto-nome`)
- **Modifier** — variação do bloco ou elemento (ex: `em-destaque`)

## 🛠 Tecnologias utilizadas

- HTML5
- SCSS

## 💡 Objetivo

Praticar a escrita de CSS escalável e de fácil manutenção seguindo padrões amplamente usados no mercado.
